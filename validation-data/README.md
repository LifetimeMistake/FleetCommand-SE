# Retained game measurements

These are original LCD exports supplied from actual game runs on 2026-10-19.
They are comparison inputs, not expected values generated by the simulator.
The copies preserve the original bytes, including blank lines and line endings.
Do not normalize them to make a comparison pass.

| File under `2026-10-19/` | Purpose | SHA256 of original bytes |
| --- | --- | --- |

| `game-station-dock-v1.txt` | Complete station release, return, capture, lock and hold | `8C06F7D0D83B1ADD8484A85E4550592B53CD45EE1227DE4B889B1FB00877B134` |
| `game-station-flight-v1.txt` | The same station mission's six power/waypoint cases | `AEFB2A42391A3C8AE2ACA889EC43324688FAC6BE93FB19FD89411DA790364202` |

The world was reported as survival in empty space. Exact game build and complete
world settings were not embedded in these reports, so this is not a fully
specified saved-world checkpoint. Initial attitude is recorded; positions,
velocities and rotations use each experiment's initial relative frame.

For station replay, use `dockprobe --frame-from` as shown in the repository
[README](../README.md). The launcher emits both simulated LCDs. For the older
single-craft diagnostic:

```powershell
./FleetCommand.Validation.Launcher/bin/x64/Debug/net48/FleetCommand.Validation.Launcher.exe restprobe artifacts/low-speed-simulator.txt --frame-from validation-data/2026-10-19/game-low-speed-v5.txt
```

The canonical `compare` command parses the `FCVALIDATION` suite schema, not these
`FCDIAGNOSTIC` reports. These diagnostics are raw evidence for reviewing motion,
power and connector behavior against source. A COMPLETE footer means the
experiment finished collecting observations; it does not assert equivalence.
The [station comparison](../docs/station-validation.md) documents observed
differences, their source-confirmed correction, and the remaining limitations.

Historical investigation notes refer to local `artifacts/` outputs. Those files
are intentionally ignored; the three original recordings above are the durable
subset retained for future development.
